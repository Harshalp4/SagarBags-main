Option 2: Generate from Azure Portal

  1. Go to Azure Portal
  2. Navigate to Storage Account: sagarbags
  3. Click "Shared access signature" in left menu
  4. Set permissions: Read, Write, Create, Add
  5. Set allowed services: Blob
  6. Set expiry date (e.g., 1 year from now)
  7. Click "Generate SAS and connection string"
  8. Copy the SAS token (starts with sv=)
  9. Paste above and click Save
